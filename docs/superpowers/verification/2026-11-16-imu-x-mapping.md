## 回放方法与可重复命令

回放工具：[replay-imu-x-mapping.py](../../../scripts/replay-imu-x-mapping.py)。四份原 CSV 只读，各排除第 2 行 schema=0 的启动垃圾，并按采集时钟、序号及配置分段，选取各自最新连续试验；不把共有旧记录重复算成试验。

旧输入已在导航系，包含旧 X 取反。工具按三点补偿的中间时刻匹配姿态，将旧导航轮速逆解到 A 板，翻转其中 X 后重新投影到导航系，使用原有补偿后加速度与实际参数回放生产 C 卡尔曼。修正结果按 X/Y 同号回转到公共速度。原实现的重置仅用于原实现回放，修正方案保留自身滤波状态，不强行继承旧拒绝。

```powershell
python scripts/replay-imu-x-mapping.py `
  --forward 'D:\QQ聊天记录\小陀螺前进320cm.csv' `
  --left 'D:\QQ聊天记录\小陀螺向左320cm.csv' `
  --right 'D:\QQ聊天记录\右移动320cm.csv' `
  --spin 'D:\QQ聊天记录\小陀螺行进.csv' `
  --forward-window 497.929 503.053 `
  --left-window 646.391 653.634 `
  --right-window 275.632 281.371 `
  --output-dir build/imu-x-mapping-replay-final
```

输出目录必须尚不存在。该次结果保存为 `build/imu-x-mapping-replay-final/summary.json` 与 `report.md`，包含原文件和回放源码 SHA256、行号、时钟、实际参数、姿态匹配/插值数量、积分窗口及敏感性。回放后已核对保存的源码哈希与当前源码一致。

净位移为 `||积分 v_navigation dt||`，不是旋转机体系分量积分或速度模积分。三个位移窗沿用此前分析的指令前约 0.5 s 至指令后约 1 s；左移包含末尾小幅修正。JSON 另列长短缓冲窗、仅左移主动作结果，避免以选窗掩盖偏差。右移 3.20 m 为用户明确确认的实测起终点距离；前进/左移按文件名提供的 320 cm 作为长度参考，未据此声称绝对航向正确。

原结果复现：自转行进中已知重置初态的 1963 次调用与记录最大差 `8.09e-7 m/s`；其余未知初态段排除前 100 次调用（名义 2 s），前进/左移/右移/行进最大差分别 `6.44e-7 / 6.84e-7 / 6.76e-7 / 6.82e-7 m/s`，均零不匹配。未知初态收敛验证与已知初态精确验证分开统计，不能互相替代。

同一评分窗内，融合速度与配对轮速的二维差 RMS：前进 `0.755→0.134 m/s`，向左 `0.610→0.137 m/s`，行进 `0.600→0.194 m/s`，右移 `0.053→0.051 m/s`。这是输入输出一致性指标，轮速不是独立速度真值。

## 验证边界与剩余问题

此次是记录的配对导航输入回放，不重演 CAN、轮速历史配对、姿态解算和中心补偿。旧拒绝后的预热期间未记录的输入无法恢复；修正回放保留这些记录缺口。少量中间姿态以 SLERP 补齐，各段初始缺失姿态及未知滤波初态已记录，评分/位移窗均避开初始预热。入口、出口和状态路径另由真实适配器回归验证。

修正消除了本批数据的方向相消及 34 次拒绝，但自转向左仍高估约 14.85%，不能据此通过精度验收。静止条件相符的右移尾段残余速度 RMS 约 `0.0042 m/s`，前进约 `0.0012 m/s`，说明偏置问题仍在。未进一步调整噪声、安装距离或增加静止约束；`CONFIG_VERIFIED=0` 保留。没有烧录硬件或推送远端。
